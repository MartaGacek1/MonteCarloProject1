## The first Monte Carlo project - November 2024

The project is connected to Monte Carlo methods. The aim is to generate and analyse pseudorandom numbers. The generators I used are LCG, GLCG, RC4 and Xorshift. I also chose some useful statistical tests, which are chi-square test, Kolmogorow-Smirnow test, series test and frequency monobit test.
The project is written in Polish.
